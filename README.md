# FraudShield

FraudShield is a fraud detection and transaction monitoring system designed to identify potentially fraudulent transactions using machine learning and rule-based analysis.

## Features

- Fraud detection using Machine Learning
- Rule-based transaction monitoring
- Risk classification
- Transaction dashboard
- Fraud alerts
- Data analysis and reporting

## Technologies Used

- Python
- Flask
- Scikit-learn
- SQLite
- HTML
- CSS
- Chart.js
